🧠 1. Ментальная модель: как думает Пролог?

В обычных языках (C#, Python, C++) вы пишете инструкции: «возьми это, проверь условие, повтори цикл». В Прологе вы создаете мир знаний (базу фактов и правил) и задаете вопросы (цели), а Пролог сам находит логические следствия!

3 кита Пролога:

  • Факты (Facts): Аксиомы, о которых известно, что они истинны. Например: likes(tom, baseball). (Тому нравится бейсбол).
  • Правила (Rules): Формулы вывода логики первого порядка: «Голова истинна, ЕСЛИ тело истинно». Например: 
    likes(bill, Activity) :- likes(tom, Activity).
    (Биллу нравится любая активность, которая нравится Тому).
  • Унификация и Backtracking: Пролог примеряет вопрос к фактам. Если натыкается на тупик, он откатывается назад к предыдущей развилке и ищет альтернативные пути.

Анатомия программы в Visual Prolog 5.2:

В отличие от обычного Пролога (где типы динамические), Visual Prolog 5.2 строго типизирован для максимальной скорости компиляции:

domains
  % 1. Определение пользовательских типов данных (синонимов типов)
  person = symbol

predicates
  % 2. Объявление предикатов и типов их аргументов
  likes(person, symbol)

clauses
  % 3. Предложения: факты и правила
  likes(tom, baseball).
  likes(bill, Act) :- likes(tom, Act).

goal
  % 4. Запрос к системе (что нужно доказать/найти)
  likes(bill, What).

⚙️ 2. Настройка среды Visual Prolog 5.2

Чтобы запускать программы в режиме тестирования целей (Test Goal / Ctrl+G):

  1. Запустите Visual Prolog: C:\VIP\BIN\WIN\32\vip.exe
  2. Создайте базовый проект через Project | New Project:
    • В поле Base Directory укажите: C:\VIP\DOC\Examples\TestGoal
    • В поле Project Name укажите: TestGoal
    • Отметьте галочку Multiprogrammer Mode
  3. На вкладке Target нажмите Create.
  4. Откройте Options | Project | Compiler Options (вкладка Warning):
    • Включите переключатель Nondeterm (чтобы предикаты могли выдавать все решения).
    • Снимите галочки Non Quoted Symbols, Strong Type Conversion Check.
  5. Откройте файл с программой через File | Open (например, Lab1_5.PRO) и нажмите Project | Test Goal (Ctrl+G)!

  % --- Правила родства ---
  отец(X, Y) :- родитель(X, Y), мужчина(X).
  мать(X, Y) :- родитель(X, Y), женщина(X).

  брат(X, Y) :-
    мужчина(X), мать(M, X), мать(M, Y),
    отец(F, X), отец(F, Y), X <> Y.

  тетя(X, Y) :- родная_тетя(X, Y).
  тетя(X, Y) :- женщина(X), супруг(X, H), родной_дядя(H, Y).

  племянник(X, Y) :- мужчина(X), родитель(P, X), брат(P, Y).

  дедушка(X, Y) :- мужчина(X), родитель(X, P), родитель(P, Y).
  бабушка(X, Y) :- женщина(X), родитель(X, P), родитель(P, Y).

  прадедушка(X, Y) :- мужчина(X), родитель(X, P), дедушка(P, Y).
  прадедушка(X, Y) :- мужчина(X), родитель(X, P), бабушка(P, Y).

  прабабушка(X, Y) :- женщина(X), родитель(X, P), дедушка(P, Y).
  прабабушка(X, Y) :- женщина(X), родитель(X, P), бабушка(P, Y).

  двоюродный_дедушка(X, Y) :- родитель(P, Y), родной_дядя(X, P).
  двоюродная_бабушка(X, Y) :- родитель(P, Y), родная_тетя(X, P).

  двоюродный_дядя(X, Y) :- родитель(P, Y), двоюродный_брат(X, P).
  двоюродная_тетя(X, Y) :- родитель(P, Y), двоюродная_сестра(X, P).

  внучатый_племянник(X, Y) :- мужчина(X), родитель(P, X), племянник(P, Y).
  внучатый_племянник(X, Y) :- мужчина(X), родитель(P, X), племянница(P, Y).

  внучатая_племянница(X, Y) :- женщина(X), родитель(P, X), племянник(P, Y).
  внучатая_племянница(X, Y) :- женщина(X), родитель(P, X), племянница(P, Y).

  % --- Свойство (брачные отношения) ---
  муж(X, Y) :- мужчина(X), супруг(X, Y).
  жена(X, Y) :- женщина(X), супруг(X, Y).

  тесть(X, Y) :- мужчина(Y), жена(W, Y), отец(X, W).
  теща(X, Y) :- мужчина(Y), жена(W, Y), мать(X, W).

  свекор(X, Y) :- женщина(Y), муж(H, Y), отец(X, H).
  свекровь(X, Y) :- женщина(Y), муж(H, Y), мать(X, H).

  невестка(X, Y) :- женщина(X), муж(H, X), родитель(Y, H).
  невестка(X, Y) :- женщина(X), муж(H, X), брат(Y, H).
  невестка(X, Y) :- женщина(X), муж(H, X), сестра(Y, H).

  зять(X, Y) :- мужчина(X), жена(W, X), родитель(Y, W).
  зять(X, Y) :- мужчина(X), жена(W, X), брат(Y, W).
  зять(X, Y) :- мужчина(X), жена(W, X), сестра(Y, W).

  шурин(X, Y) :- мужчина(Y), жена(W, Y), брат(X, W).
  свояченица(X, Y) :- мужчина(Y), жена(W, Y), сестра(X, W).

  деверь(X, Y) :- женщина(Y), муж(H, Y), брат(X, H).
  золовка(X, Y) :- женщина(Y), муж(H, Y), сестра(X, H).

🎯 5. Проверь себя (Тест на понимание)

1. Что произойдет, если в Visual Prolog задать цель: likes(Who, _)?

Символ _ (анонимная переменная) сопоставляется с любым объектом, но никогда не связывает значение и не выводит его пользователю.

2. Почему в Visual Prolog дизъюнкцию условий правила обычно оформляют отдельными предложениями (clauses)?

В Turbo/Visual Prolog конструкции вида (A ; B) внутри предложения вызывают ошибку 406. Дизъюнкция логично реализуется альтернативными предложениями с одинаковой головой!

3. Кто приходится «шурином» для Алекса (Alex)?

Шурин — это брат жены! Жена Алекса — Джули (Juli). Брат Джули — Александр (Alexandr). Значит, шурин Алекса — Александр!
