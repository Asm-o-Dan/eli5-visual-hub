Файловая система Linux: Inode и Ссылки

Ментальная модель на пальцах: почему имя файла — это не сам файл, как устроена таблица Inode, чем отличаются жесткие ссылки от символических и как работает удаление в Linux.

❌ Наивная интуиция (Windows-стиль)
  • ⛔ «Файл — это его имя и папка, где он лежит».
  • ⛔ «Жесткая ссылка — это просто скрытая копия файла».
  • ⛔ «Команда rm стирает данные с диска навсегда».
  • ⛔ «Каталог хранит внутри себя все файлы физически».
✅ Реальность ядра Linux (POSIX / Unix)
  • ⚡ Файл — это Inode: имя — всего лишь указатель в таблице каталога на номер индексного дескриптора.
  • ⚡ Жесткая ссылка: второе имя для того же Inode (0 байт лишних данных на диске!).
  • ⚡ rm = Unlink: команда удаляет запись в каталоге. Данные стираются, только когда счетчик ссылок Inode = 0.
  • ⚡ Каталог: это служебный файл-таблица с парами (имя_файла → номер_inode).

🧭 Навигация: . и .. и слэш /

Дерево Linux имеет единственный корень /. Дисков C:, D: в Unix-модели нет — любые разделы монтируются в каталоги общего дерева.

  • / — Корень файловой системы (абсолютный путь всегда начинается с него).
  • . — Текущий рабочий каталог (например: ./script.sh).
  • .. — Родительский каталог уровнем выше (например: cd ../..).
cd /home/user/docs # Абсолютный переход
cd ../pictures # Относительный переход

⚙️ Специальные файлы устройств (/dev)

В UNIX действует парадигма: «Всё есть файл». Даже видеокарта, клавиатура и накопители представлены в файловой системе.

  • Символьные (c): побайтовый поток без кэша (терминал /dev/tty, генератор /dev/urandom, черная дыра /dev/null).
  • Блочные (b): блочный обмен с кэшированием в ОЗУ (диски /dev/sda, NVMe /dev/nvme0n1).

💡 Секрет: Эти файлы занимают 0 байт на диске! Они хранят лишь Major/Minor номер драйвера в ядре.

📝 Текстовый редактор vi: 3 режима

Редактор vi (и vim) — модальный редактор. Символы на клавиатуре делают разное в зависимости от режима:

  • 1. Командный (Esc): перемещение по файлу (hjkl), удаление строк (dd), копирование (yy), вставка (p).
  • 2. Ввод текста (i / a): прямой набор текста.
  • 3. Режим Ex (:): команды в нижней строке: :w (сохранить), :q! (выйти без сохранения), :wq (сохранить и выйти).

👁️ Просмотр файлов: cat vs less

Какой инструмент выбрать для чтения файлов в консоли:

  • cat file.txt — вываливает весь файл в терминал разом. Удобно для маленьких конфигов на 10 строк.
  • less file.log — открывает постраничный интерактивный просмотр.
⚡ Почему `less` лучше на гигантских файлах: Он не загружает гигабайтный лог в оперативную память, а читает диск порциями по мере прокрутки (Space, стрелки, /поиск, выход по q).
