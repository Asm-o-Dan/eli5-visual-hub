2. Задание 2: Определение диапазона устойчивости по усилению k

Замкнутая система с тремя последовательными звеньями и единичной отрицательной обратной связью (Вариант 18):

W₁(p) = (p + 5) / (50p + 1)
W₂(p) = 12 / (25p + 2)
W₃(p) = 20k / (7p + 10)
W_раз(p) = W₁ · W₂ · W₃ = [ 240k·(p + 5) ] / [ (50p + 1)(25p + 2)(7p + 10) ]

Характеристическое уравнение замкнутой системы 1 + W_раз(p) = 0:

A(p) = 8750 p³ + 13375 p² + (1264 + 240k) p + (20 + 1200k) = 0
a₃ = 8750 > 0
a₂ = 13375 > 0
a₁ = 1264 + 240k
a₀ = 20 + 1200k

Критический определитель Гурвица для n = 3:

Δ₂ = a₂ · a₁ - a₃ · a₀ = 13375 · (1264 + 240k) - 8750 · (20 + 1200k)
Δ₂(k) = 16 731 000 - 7 290 000 · k > 0

k < 16 731 000 / 7 290 000 = 1859 / 810 ≈ 2.295
1.00 УСТОЙЧИВА
Определитель Δ₂(k): +9.441 × 10⁶ | Критическое значение: k_крит = 2.295
Слева: переходная характеристика h(t). Справа: перемещение полюсов на комплексной плоскости.
