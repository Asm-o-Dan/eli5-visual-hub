Конструктор Диаграмм & Инспектор Параметров

Как выбрать идеальный график, понять универсальные и уникальные параметры Matplotlib/Seaborn и мгновенно узнавать их прямо в IDE.

🧭 Ментальная модель: как выбрать правильный график

📊 Сравнение (Comparison)

Сравнить категории между собой по дискретному показателю.

plt.bar plt.barh sns.barplot

📉 Распределение (Distribution)

Понять форму данных, разброс, нормальность и выбросы.

sns.histplot sns.kdeplot plt.hist

🔵 Связь и Тренд (Correlation)

Зависимость двух непрерывных числовых величин + регрессия.

sns.regplot plt.scatter sns.scatterplot

🥧 Доли и Состав (Composition)

Показать структуру целого (только при 3-5 крупных секторах!).

plt.pie

🗺️ Матрица плотности (Density)

Двумерное пересечение категорий (например, Город x Месяц).

sns.heatmap plt.imshow

📦 Квартили и Разброс (Boxplot)

Медиана, межквартильный размах (IQR) и выбросы категорий.

sns.boxplot sns.violinplot

📈 Временной ряд (Time Series)

Непрерывное изменение метрики по времени или шагам.

plt.plot sns.lineplot

🧬 Анатомия параметров: «Общие» vs «Уникальные»


    

      

        В Matplotlib и Seaborn параметры делятся на две категории: универсальные (работают почти для любого графика через объект Axes или Figure) и уникальные (специфичные для конкретной геометрии графика).
      


      

        
          

            Параметр
            Тип
            Где применяется
            Что делает / Значение по умолчанию
          

        
        
          

            figsize=(w, h)
            Универсальный
            plt.figure()
            Размер холста в дюймах. Без него графики получаются сжатыми.
          

          

            color / palette
            Универсальный
            Все графики
            Цвет одного элемента или палитра (в Seaborn: palette='muted' / 'YlGnBu').
          

          

            alpha
            Универсальный
            Все графики
            Прозрачность от 0.0 (невидимый) до 1.0 (глухой). Предотвращает перекрытие точек.
          

          

            plt.grid(axis='...')
            Универсальный
            Все (кроме Pie)
            Сетка: axis='x', axis='y' или 'both', стиль linestyle='--'.
          

          

            plt.tight_layout()
            Универсальный
            Перед plt.show()
            Автоматически настраивает поля, чтобы подписи осей не обрезались краями холста.
          

          

            bins=35
            Уникальный
            hist / histplot
            Количество корзин (интервалов) для разбивки непрерывных данных.
          

          

            kde=True
            Уникальный
            sns.histplot
            Накладывает кривую ядерной оценки плотности (Kernel Density Estimation).
          

          

            autopct='%1.1f%%'
            Уникальный
            plt.pie
            Строка форматирования процентов на секторах круговой диаграммы.
          

          

            explode=(0.05, ...)
            Уникальный
            plt.pie
            Кортеж смещения каждого сектора от центра (эффект выдвинутого кусочка пиццы).
          

          

            annot=True, fmt='d'
            Уникальный
            sns.heatmap
            Вывод числовых значений прямо в ячейках матрицы (fmt='d' — целые, '.2f' — дроби).
          

          

            scatter_kws / line_kws
            Уникальный
            sns.regplot
            Словари параметров для раздельной настройки точек (размер s) и линии тренда (цвет, ширина).
          

        
      

    


    
    
⚡ Секретные хоткеи: как мгновенно узнавать параметры в IDE


    

      
      

        
Google Colab & Jupyter Shift + Tab

        
    
          
  • Shift + Tab — всплывающее окно с сигнатурой функции и списком всех параметров прямо во время ввода.
    • 
          
  • Shift + Tab + Tab — развернуть полную документацию на весь экран.
    • 
          
  • sns.histplot? — напечатать знак вопроса перед/после функции и запустить ячейку — откроется официальный docstring.
    • 
          
  • ??sns.histplot — два знака вопроса открывают исходный код реализации функции на чистом Python!
    • 
        

      


      
      

        
DataGrip, PyCharm, VS Code Ctrl + P

        
    
          
  • Ctrl + P (Parameter Info) — мгновенный список ожидаемых аргументов внутри круглых скобок вызова.
    • 
          
  • Ctrl + Q (PyCharm/DataGrip) или Ctrl + Space (VS Code) — быстрая документация с типами аргументов.
    • 
          
  • Ctrl + Click (или F12) — переход прямо к определению функции в библиотеке.
    • 
          
  • Alt + Enter — быстрые исправления импортов и параметров.
    • 
        

      


      
      

        
Python CLI / Консоль help()

        
    
          
  • help(plt.barh) — выводит текстовую документацию в терминал со списком всех аргументов и примерами.
    • 
          
  • dir(sns) — список всех доступных функций модуля.
    • 
          
  • В IPython: plt.plot? или import inspect; inspect.signature(plt.pie).
    • 
        

      

    


    

      
💡

      

        Золотое правило инженеров: Никогда не заучивайте параметры наизусть. Достаточно помнить: «Какую идею я визуализирую?», а список аргументов извлекается за 0.5 секунды комбинацией Shift+Tab в Colab или Ctrl+P в DataGrip/PyCharm.
