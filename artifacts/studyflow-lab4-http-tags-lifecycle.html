Сетевой справочник по HTTP: Жизненный цикл и Runtime-типы

Разбираем на пальцах переход от статических данных к реальному асинхронному протоколу HTTP: как связать Fetch API с интерфейсом React, защититься от поломок сети и почему TypeScript не защищает вас во время исполнения.

❌ Иллюзия типов (Как делают новички)
  • ❌ import tags from './tags.json' — нет сетевого обмена, данные намертво вшиты в бандл.
  • ❌ data as Tag[] — самообман: при 404 или HTML-ошибке приложение упадёт в белый экран.
  • ❌ useEffect без очистки — утечки памяти и ошибка Can't perform a state update on an unmounted component.
  • ❌ Ошибка сети сбрасывает введённый черновик пользователя.
✅ Промышленный подход (ЛР 4)
  • ✅ Реальный GET /demo/tags.json через fetch() с проверкой response.ok.
  • ✅ Runtime-валидация: isTag и parseTags проверяют структуру до передачи в стейт.
  • ✅ AbortController + active=false отменяют запрос при размонтировании формы.
  • ✅ Черновик формы изолирован: кнопка «Повторить» перезапрашивает теги, не стирая поля.
📡 Архитектурный конвейер сетевой загрузки
1
Type Guard vs 'as'
as Tag[] существует только для редактора VS Code. В браузере его стирает Babel/Vite. Функция isTag() проверяет реальные байты в рантайме.
2
AbortController
Если юзер за 0.1 секунды открыл и закрыл форму — браузер физически отменяет HTTP-пакет, а флаг active=false блокирует попытку обновить стейт мёртвого экрана.
3
Изоляция черновика
Сетевой запрос живёт в useTags, а текст задачи — в draft. При ошибке сети черновик не стирается, кнопка «Повторить» перезапускает только сеть.

🎓 Шпаргалка для защиты (Вопросы Бричага Д.В.)
Импорт в TypeScript компилируется сборщиком прямо в JS-файл (синхронно, без сети). Запрос к файлу из public через fetch — это настоящий асинхронный HTTP-запрос в браузере с заголовками, статусами (200/404) и возможностью отмены.
fetch() отклоняет промис ТОЛЬКО при физическом падении сети. Если сервер вернул 404 или 500, fetch считает это успешным обменом. Проверка response.ok выбрасывает ошибку, предотвращая разбор HTML-страницы ошибки как JSON.
Конструкция 'as' существует только во время компиляции TypeScript и полностью удаляется при сборке. В рантайме браузера она не выполняет никаких проверок. Реальную валидацию делают User-Defined Type Guard (isTag) и функция parseTags.
Она вызывает controller.abort(), прерывая HTTP-запрос на уровне браузера, и устанавливает active = false, гарантируя, что завершившийся промис не попытается обновить стейт уже уничтоженного компонента формы.
Это принцип нормализации данных. ID ('lab') — постоянный компактный ключ для связей. Название ('Лабораторная') может измениться в справочнике (перевод, исправление опечатки), но связи и записи в базе при этом не сломаются.
