Соединение звеньев и устойчивость САУ

Интерактивный симулятор преобразования структурных схем, анализ разомкнутой и замкнутой систем, годограф Найквиста, критерий Гурвица и феномен срыва устойчивости при обратной связи.

🧩 1. Базовые правила соединения звеньев

Любая сложная система автоматического регулирования сводится к комбинации трех элементарных типов соединений:

1. Посл. Последовательное

Выход одного звена подается на вход следующего.

W_об(p) = W₁ · W₂ · W₃

Полюса системы — это совокупность полюсов всех звеньев. Устойчива только если устойчивы ВСЕ звенья.

2. Парал. Параллельное согласное

Один общий вход, выходы суммируются: y = y₁ + y₂ + y₃.

W_об(p) = W₁ + W₂ + W₃

Передаточные функции складываются при общем знаменателе.

3. ОС Встречно-параллельное

Выход через звено обратной связи возвращается на вход.

W_зам = W₁ / (1 ± W₁·W₂)

«+» — отрицательная ОС (ООС). Полюса смещаются! Устойчивая разомкнутая система может стать неустойчивой!

📐 2. Аналитический расчет Варианта 18

Структура Варианта 18:

Цепь обратной связи: единичная отрицательная обратная связь (W_ос(p) = 1).

1. Разомкнутая система:

W_раз(p) = W₁ · W₂ · W₃ = 1000 / [ (1 + 0.2p) · (p + 20) · (1 + 0.04p) ] Нормализованная форма: W_раз(p) = 125000 / [ p³ + 50p² + 725p + 2500 ] Полюса разомкнутой цепи: p₁ = -5, p₂ = -20, p₃ = -25 (Все Re < 0 => УСТОЙЧИВА!)

2. Замкнутая система:

W_зам(p) = W_раз(p) / [ 1 + W_раз(p) ] = 125000 / [ p³ + 50p² + 725p + 127500 ] Характеристическое уравнение: p³ + 50p² + 725p + 127500 = 0 Определитель Гурвица: Δ₂ = a₁·a₂ - a₀·a₃ = 50 · 725 - 1 · 127500 = -91250 < 0 (НЕУСТОЙЧИВА!) Полюса замкнутой системы: p₁ = -67.35, p₂,₃ = +8.67 ± j42.64 (Re > 0 => Автоколебания!) Критический коэффициент: K_крит = 270. При K = 1000 система глубоко неустойчива.
