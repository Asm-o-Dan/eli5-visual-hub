Соединение звеньев, АЧХ, ФЧХ и устойчивость

Интерактивный конспект и тренажер по всем 5 пунктам задания: вывод передаточных функций, аналитические АЧХ и ФЧХ, частотный годограф (АФЧХ), полюса и доказательство устойчивости разомкнутой цепи.

🧩 1. Базовые правила структурных преобразований

Любая сложная динамическая система декомпозируется на три элементарных типа соединений звеньев:

1. Посл. Последовательное

Выход одного звена подается на вход последующего.

W_об(p) = W₁ · W₂ · W₃

Полюса соединения — это объединение полюсов звеньев. Устойчиво тогда и только тогда, когда устойчивы ВСЕ звенья!

2. Парал. Параллельное согласное

Общий вход, выходы суммируются: y = y₁ + y₂ + y₃.

W_об(p) = W₁ + W₂ + W₃

Передаточные функции складываются при приведении к общему знаменателю.

3. ОС Встречно-параллельное

Выход через звено обратной связи возвращается на вход.

W_зам = W₁ / (1 ± W₁·W₂)

При единичной отрицательной ОС (ООС): W_зам = W_раз / [1 + W_раз]. Знаменатель меняется!

📐 2. Результаты выполнения 5 пунктов задания (Вариант 18)

Исходные параметры Варианта 18:

• Звено 1: W₁(p) = 10 / (1 + 0.2p) = 50 / (p + 5), где k₂ = 10, T₂ = 0.2 с

• Звено 2: W₂(p) = 20 / (p + 20), где k₁ = 20

• Звено 3: W₃(p) = 5 / (1 + 0.04p) = 125 / (p + 25), где k₃ = 5, T₁ = 0.04 с

Пункт 1. Передаточная функция разомкнутой системы W_раз(p):

W_раз(p) = W₁(p) · W₂(p) · W₃(p) = 1000 / [ (1 + 0.2p)(p + 20)(1 + 0.04p) ] Стандартная форма: W_раз(p) = 1000 / [ 0.008p³ + 0.4p² + 5.8p + 20 ] Нормированная форма: W_раз(p) = 125000 / [ p³ + 50p² + 725p + 2500 ] Статическое усиление: k₀ = W_раз(0) = 50 (33.98 дБ)

Пункт 2. Передаточная функция замкнутой системы W_зам(p):

W_зам(p) = W_раз(p) / [ 1 + W_раз(p) ] = 1000 / [ 0.008p³ + 0.4p² + 5.8p + 1020 ] Нормированная форма: W_зам(p) = 125000 / [ p³ + 50p² + 725p + 127500 ] Статический коэффициент передачи: k_зам = 125000 / 127500 ≈ 0.9804 (ошибка 1.96%)

Пункт 3. Частотные характеристики разомкнутой цепи:

Комплексный коэффициент: W_раз(jω) = 1000 / [ (1 + 0.2jω) · (20 + jω) · (1 + 0.04jω) ] АЧХ: A(ω) = 1000 / [ √(1 + 0.04ω²) · √(400 + ω²) · √(1 + 0.0016ω²) ] ФЧХ: φ(ω) = -arctg(0.2ω) - arctg(ω / 20) - arctg(0.04ω) Частота φ = -90°: ω = √50 ≈ 7.071 рад/с (P = 0, Q ≈ -26.19) Частота φ = -180°: ω_π = √725 ≈ 26.926 рад/с (Q = 0, P ≈ -3.704)

Пункты 4 и 5. Характеристическое уравнение, полюса и устойчивость:

Характеристическое уравнение: A_раз(p) = (1 + 0.2p)(p + 20)(1 + 0.04p) = 0 Полюса: • p₁ = -1 / 0.2 = -5 с⁻¹ (Re = -5 < 0, левая полуплоскость) • p₂ = -20 с⁻¹ (Re = -20 < 0, левая полуплоскость) • p₃ = -1 / 0.04 = -25 с⁻¹ (Re = -25 < 0, левая полуплоскость) Вывод об устойчивости: Так как ВСЕ полюса p₁, p₂, p₃ имеют строго отрицательную вещественную часть (Re < 0), РАЗОМКНУТАЯ СИСТЕМА ЯВЛЯЕТСЯ АСИМПТОТИЧЕСКИ УСТОЙЧИВОЙ!
