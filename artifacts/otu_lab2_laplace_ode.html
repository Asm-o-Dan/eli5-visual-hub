🏛️ 4 Столпа математических основ теории управления
Столп 1
Фундаментальная система решений (ФСР)
Совокупность n линейно независимых решений x_k(t), чей определитель Вронского W(t) ≠ 0. Базис пространства всех свободных движений системы.
Столп 2
Дифференцирование оригинала
Операция d/dt эквивалентна умножению на комплексный оператор p за вычетом начального условия: L{x'} = pX(p) - x(0). Задача Коши решается алгебраически.
Столп 3
Теорема разложения Хевисайда
Разложение рациональной дроби X(p) по полюсам p_k через вычеты. Каждому действительному полюсу соответствует e^(p_k·t), а паре ±jω — гармоника cos(ωt).
Столп 4
Связь s-плоскости с устойчивостью
Левая полуплоскость (Re(p) < 0) — устойчивые затухающие переходные процессы. Правая (Re(p) > 0) — катастрофический экспоненциальный разгон.

1. Как начальные условия задачи Коши учитываются в методе Лапласа? ▼
По теореме дифференцирования оригинала: L{x'} = pX(p) - x(0) и L{x''} = p²X(p) - px(0) - x'(0). Начальные значения x(0) и x'(0) автоматически переносятся в правую часть алгебраического уравнения, полностью исключая необходимость решать отдельную СЛАУ для поиска констант C1, C2.
2. Как формулируется вторая теорема разложения Хевисайда? ▼
Если изображение X(p) = Q(p)/D(p) — правильная дробь, то оригинал x(t) равен сумме вычетов по всем полюсам p_k: x(t) = ∑ Res [ X(p)·e^(pt) ]. Для простых полюсов вычет равен lim_{p→p_k} [(p - p_k)·X(p)·e^(pt)].
3. Почему система в Варианте №15 неустойчива? ▼
Характеристические корни λ1 = 7, λ2 = 8 для Уравнения 1 и λ1 = 6, λ2 = 12 для Уравнения 2 строго положительны (Re(λ) > 0). По критерию устойчивости Ляпунова, если хотя бы один корень лежит в правой полуплоскости, свободные моды экспоненциально нарастают при t → ∞.
4. Откуда в решении Уравнения 2 появились тригонометрические функции sin(t) и cos(t)? ▼
Внешнее воздействие F(t) = cos(t) имеет изображение по Лапласу p / (p² + 1). Знаменатель содержит чисто мнимые комплексно-сопряженные полюса p = ±j, которые при обратном преобразовании Лапласа формируют незатухающую вынужденную гармонику (71/5365)·cos(t) - (18/5365)·sin(t).
5. В чем физический смысл определителя Вронского? ▼
Вронскиан W(t) является индикатором фазового объема фундаментальной системы решений. Если W(t) ≠ 0, траектории решений не склеиваются и образуют линейно независимый базис n-мерного фазового пространства.
