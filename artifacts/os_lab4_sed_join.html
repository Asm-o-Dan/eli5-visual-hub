Потоковая обработка и фильтрация данных в Linux

Как работают конвейеры, память sed (pattern vs hold space) и реляционный join без использования awk.

⚡ Ментальная модель за 0.3 секунды

Linux Pipeline — это сборочный конвейер на заводе. Вместо сохранения детали в ящик (на диск), первая команда передаёт результат следующей через трубу в оперативной памяти (pipefs 64KB). sed обрабатывает по одной строке за раз, а join сопоставляет ключи двух отсортированных очередей.

🚫 Типичные антипаттерны студентов

  • Использование awk, когда преподаватель строго его запретил.
  • Попытка запустить join на неотсортированных файлах (половина строк теряется).
  • Создание десятка временных файлов temp1.txt, temp2.txt вместо конвейера |.
  • Сортировка дат 01-MAR-22 как строк без перевода месяца в число.

✨ Чистое инженерное решение (No Slop)

  • Потоковая нормализация: sed переводит MAR в 03 и собирает ключ YY-MM-DD.
  • Подготовка данных: sort -k перед join гарантирует single-pass слияние $O(N+M)$.
  • Аггрегация сумм в Bash: ассоциативный массив declare -A считает выручку без внешних утилит.
  • Однострочный стриминг: конвейер со сверткой в sed и eval $((a+b)).

🎯 Контрольные вопросы преподавателя к защите

1. Что произойдёт с join, если не отсортировать файлы перед вызовом?
Показать ответ
join использует однопроходное сканирование (two-pointer single pass $O(N+M)$). При нарушении сортировки утилита прервёт сопоставление с предупреждением или пропустит строки. Данные будут потеряны.
2. Чем оператор > отличается от >> на уровне ядра ОС?
Показать ответ
> открывает файл с флагом O_TRUNC (очищает существующий файл до 0 байт). >> открывает с флагом O_APPEND (дописывает новые данные в конец).
3. Как на защите развернуть сортировку товаров от старых к новым (по возрастанию)?
Показать ответ
Достаточно убрать ключ -r у утилиты sort -r, оставив просто sort (или заменить -k1,1rn на -k1,1n).
4. Что обозначает символ дефиса «-» на месте имени файла?
Показать ответ
Символ - означает чтение из стандартного потока ввода (stdin) вместо файла на диске (например: cat file.txt | paste other.txt -).
