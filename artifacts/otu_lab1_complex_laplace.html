0.3-Секундная инженерная интуиция: Зачем ТАУ комплексные числа?

В реальном мире автоматические системы описываются громоздкими дифференциальными уравнениями во времени t. Решать их напрямую через интегралы неудобно. Преобразование Лапласа переносит дифференциальное уравнение в алгебраическую комплексную p-плоскость (p = σ + jω), превращая операцию дифференцирования d/dt в элементарное умножение на p.

Левая полуплоскость (Re(p) < 0)
Полюсы дают затухающие экспоненты e^(-σt). Система устойчива.
Правая полуплоскость (Re(p) > 0)
Полюсы дают расходящиеся моды e^(+σt). Система неустойчива! В Варианте 18 полюс p0 = +0.5 > 0!
Мнимая ось (p = jω)
Чисто гармонические автоколебания с частотой ω (граница устойчивости).

3. Полюсы, вычеты и устойчивость (Задание 3)

s-Plane & Двукратный полюс (m = 2)

Функция: W(p) = (6p + 2) / [(2p - 1)(4p - 2)]
• Знаменатель: (2p - 1)·2(2p - 1) = 8·(p - 0.5)²
• Полюс: p0 = 0.5 (кратность m = 2)
• Вычет функции: Res[W(p), 0.5] = 3/4 = 0.75
• Начальное значение: w(0) = 0.75

⚠️ Диагноз устойчивости: СТРУКТУРНО НЕУСТОЙЧИВА
Полюс p0 = +0.5 лежит в правой комплексной полуплоскости (Re > 0). Моды e^(0.5t) и t·e^(0.5t) неограниченно возрастают во времени при t → ∞.
Функция-оригинал по второй теореме разложения:
w(t) = (0.75 + 0.625·t) · e^(0.5·t)

Проверка начального значения:
w(0) = 0.75 = lim_{p→∞} p·W(p) = 6/8 = 0.75

Задание 2: Преобразование Лапласа

Оригинал: y(t) = 1 + 2·sin(t) + 15·e^(2t)
Изображение:
Y(p) = 1/p + 2/(p² + 1) + 15/(p - 2)

В виде единой дроби:
Y(p) = 2·(8p³ + 6p - 1) / [p(p - 2)(p² + 1)]

Использованы линейность, табличные образы 1(t), sin(t) и теорема смещения.

Задание 3: Вычеты и оригинал

Изображение: W(p) = (6p + 2) / [(2p - 1)(4p - 2)]
Полюс: p0 = 0.5 (кратность m = 2)
Вычет функции: Res[W(p), 0.5] = 0.75
Оригинал: w(t) = (0.75 + 0.625t) · e^(0.5t)
Начальное значение: w(0) = 0.75 = lim_{p → ∞} p·W(p)
Устойчивость: неустойчиво из-за p0 = +0.5 > 0.
