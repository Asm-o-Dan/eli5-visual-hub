Краш целостности Room на Poco M7: анатомия ошибки и Hotfix

Почему добавление новой Room-сущности без изменения версии базы данных гарантированно ломает продакшн, и как устроена миграция MIGRATION_4_5.

❌ Инцидент (P3-UNI-008 на Poco M7)
  • ⛔ В AppDatabase.kt добавили ExtractionFeedbackEntity
  • ⛔ Версию оставили прежней: version = 4
  • ⛔ Миграция MIGRATION_4_5 отсутствовала
  • 💥 Crash: Room вычислил новый хэш 3f21874a..., но в room_master_table лежал cd37015c...
✅ Hotfix-решение
  • ⚡ Создан MIGRATION_4_5.kt с чистым DDL и каскадным внешним ключом
  • ⚡ Версия поднята: @Database(..., version = 5)
  • ⚡ В DI билдер Room зарегистрирован MIGRATION_4_5
  • 🛡️ PreMigrationBackup делает снимок SQLite файла перед миграцией

📐 Механизм верификации Room Identity Hash

🗄️ DDL сущности extraction_feedback

Таблица для хранения телеметрии и качества извлечения сущностей из уведомлений/чеков с автоматическим удалением при очистке события (CASCADE).

CREATE TABLE IF NOT EXISTS `extraction_feedback` (
  `id` INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
  `event_id` INTEGER NOT NULL,
  `features_json` TEXT NOT NULL,
  `verdict` TEXT NOT NULL,
  `extractor_kind` TEXT NOT NULL,
  `user_action` TEXT,
  `created_at` INTEGER NOT NULL,
  FOREIGN KEY(`event_id`) REFERENCES `event`(`id`) ON DELETE CASCADE
);

CREATE INDEX IF NOT EXISTS `index_extraction_feedback_event_id` ON `extraction_feedback` (`event_id`);
CREATE INDEX IF NOT EXISTS `index_extraction_feedback_created_at` ON `extraction_feedback` (`created_at`);

🚀 СТАТУС: Безопасный запуск и миграция
• PreMigrationBackup создает резервную копию v4 базы.
• Room запускает MIGRATION_4_5.migrate(db).
• Новая таблица и 2 индекса созданы.
• Новый identity_hash (3f21874a...) записан в room_master_table.
01
Identity Hash детерминирован
Room генерирует хэш на основе DDL всех полей и таблиц. Любая правка сущности без инкремента версии ломает запуск.
02
Аддитивность & CASCADE
Миграция использует IF NOT EXISTS и внешний ключ ON DELETE CASCADE к event(id), сохраняя целостность данных.
03
Pre-Migration Бэкап
Перед вызовом Room PreMigrationBackup копирует основной файл БД, WAL и SHM в безопасную директорию при нехватке места или сбое.
