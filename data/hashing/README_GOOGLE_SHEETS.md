# 🚀 Инструкция: Google Таблицы + Google Apps Script (Лабораторная работа №1 «Хеширование»)

Данный скрипт превращает обычную Google Таблицу в полноценную интерактивную систему для выполнения, исследования и демонстрации Лабораторной работы №1 («Хеширование и Хеш-таблицы», 3 курс).

---

## ⚡ Быстрый старт (Установка за 1 минуту)

### Шаг 1. Создайте новую Google Таблицу
1. Перейдите в [Google Sheets](https://sheets.new) и создайте пустую таблицу.
2. Назовите её, например: «АОД - Лабораторная 1 (Хеширование)».

### Шаг 2. Откройте редактор Apps Script
1. В верхнем меню Google Таблицы выберите: **Расширения** (Extensions) ➔ **Apps Script**.
2. Откроется вкладка редактора кода. Удалите из файла Код.gs (или Code.gs) весь стандартный текст unction myFunction() { ... }.

### Шаг 3. Вставьте готовый код
1. Откройте файл data/hashing/Code.gs и скопируйте его целиком (Ctrl+A, Ctrl+C).
2. Вставьте его в редактор Apps Script (Ctrl+V).
3. Нажмите кнопку **💾 Сохранить** (Ctrl+S).

### Шаг 4. Обновите страницу таблицы
1. Вернитесь на вкладку Google Таблицы и нажмите **F5** (обновить страницу).
2. Через 2-3 секунды в верхнем меню появится новый пункт: **⚡ Хеширование (Лаб 1)**!

> При первом запуске любого действия Google запросит стандартное разовое разрешение на выполнение скрипта:
> *«Продолжить» ➔ «Дополнительные настройки» ➔ «Перейти на страницу проекта (небезопасно)» ➔ «Разрешить»*.

## 🖱️ Как привязать действия к графическим КНОПКАМ на листе

Чтобы запускать алгоритмы не только из верхнего меню, но и по красивым кнопкам прямо на листе:

1. В верхнем меню таблицы нажмите: **Вставка** (Insert) ➔ **Рисунок** (Drawing).
2. Выберите инструмент **Фигуры** (Shapes) ➔ **Скругленный прямоугольник**.
3. Задайте цвет заливки (например, синий #1e293b или изумрудный #10b981), дважды кликните по фигуре и напишите текст (например, ▶ Заполнить датасет или 🎯 Построить таблицу).
4. Нажмите **Сохранить и закрыть** в правом верхнем углу окна рисования.
5. Кнопка появится на вашем листе. Нажмите на **три точки в правом верхнем углу кнопки** ➔ **Назначить скрипт** (Assign script).
6. Введите точное имя функции из таблицы ниже:

| Надпись на вашей кнопке | Функция для назначения (в поле ввода) | Что делает |
|---|---|---|
| **📥 Заполнить датасет** | loadDataset | Создает лист «Датасет» с 30 записями Таблицы 1 и красивым форматированием |
| **🔗 Метод цепочек (M=30)** | uildChainingTablePrompt | Запрашивает столбец (1..7) и строит лист «Метод_Цепочек_M30» со связными списками и коллизиями |
| **🎯 Открытая адресация (M=60)** | uildOpenAddressingPrompt | Запрашивает вариант (1..21) и строит лист «Открытая_Адресация_M60» со статусами ячеек |
| **🔍 Найти по ключу** | searchKeyInteractive | Запрашивает ключ, показывает трассу проб, число шагов и подсвечивает строку |
| **🪦 Удалить по ключу** | deleteKeyInteractive | Находит элемент и ставит надгробие 🪦 DELETED, сохраняя целостность цепочек проб |
| **📊 Сводная оценка качества** | uildEvaluationReport | Строит лист «Оценка_Качества» со всеми 21 вариантами и сравнением с формулами Кнута |
| **🧹 Очистить таблицы** | clearGeneratedSheets | Удаляет временные листы, оставляя исходный «Датасет» |

## 🪦 Инвариант надгробий (DELETED)
При удалении записи из открытой адресации ячейка переводится в статус **«🪦 DELETED»**.
Это предотвращает разрыв цепочки проб: при последующем поиске алгоритм знает, что здесь была коллизия и элемент удален, поэтому не останавливается, а продолжает проверку следующих ячеек. При новой вставке ячейка с надгробием может быть повторно занята.
